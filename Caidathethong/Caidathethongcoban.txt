================================================================================
          HƯỚNG DẪN CÀI ĐẶT & THIẾT LẬP HỆ THỐNG CACHYOS / HYPRLAND
          (DÀNH CHO ANTIGRAVITY HOẶC NGƯỜI DÙNG CÀI ĐẶT TRÊN MÁY MỚI)
================================================================================

Tài liệu này ghi lại toàn bộ các bước thêm, xóa, sửa phần mềm, thiết lập phím tắt,
cấu hình cửa sổ, bộ gõ tiếng Việt, màn hình kép, hình nền động và các tác vụ tự động hóa đã thực hiện.
Khi cài đặt trên một thiết bị CachyOS mới, Antigravity chỉ cần đọc tài liệu này hoặc
chạy script "install.sh" đính kèm để tự động tái hiện 100% môi trường làm việc.

1. GỠ BỎ CÁC ỨNG DỤNG KHÔNG CẦN THIẾT
================================================================================
Các ứng dụng mặc định sau đây đã được gỡ bỏ khỏi hệ thống vì trải nghiệm kém hoặc
không phù hợp:
  - dolphin: Quản lý tệp của KDE, không phù hợp môi trường Hyprland/kéo thả khó chịu.
  - firefox: Trình duyệt mặc định, được thay thế bằng Cốc Cốc.
  - vim: Trình soạn thảo terminal không cần thiết.
  - kcalc / gnome-calculator: Máy tính bỏ túi.
  - qview: Trình xem ảnh cũ, trải nghiệm kém.
  - uuctl / shelly: Các tiện ích không sử dụng.
  - kwrite / gedit: Trình soạn thảo text cũ, thay bằng VS Code và Micro.

Lệnh gỡ bỏ:
  sudo pacman -Rns --noconfirm dolphin firefox vim kcalc qview 2>/dev/null || true
  # Lưu ý: Giữ lại 'micro' cho nhu cầu soạn thảo nhanh trong terminal.

2. CÀI ĐẶT CÁC PHẦN MỀM THAY THẾ & BỔ SUNG (CHUẨN WINDOWS & TỐI ƯU LINUX)
================================================================================
Các ứng dụng mới đã được cài đặt để thay thế hoàn hảo các chức năng trên và bổ sung tiện ích:

2.1. Trình duyệt Cốc Cốc (coccoc-browser):
  - Cài đặt từ AUR:
      paru -S --needed --noconfirm coccoc-browser
  - Tự động chạy khi khởi động hệ thống.
  - Tạo file desktop tùy chỉnh ~/.local/share/applications/coccoc-browser.desktop
    để hỗ trợ tìm kiếm nhanh bằng phím tắt: "c", "cc", "coccoc".

2.2. Trình soạn thảo mã nguồn VS Code (Code-OSS):
  - Cài đặt:
      sudo pacman -S --needed --noconfirm code
  - Tùy biến nhận diện: Đổi tên hiển thị từ "Code - OSS" thành "VS Code" và gắn icon
    VS Code chuẩn tại ~/.local/share/applications/code.desktop
  - Từ khóa tìm kiếm nhanh: "v", "vs", "vscode", "code".

2.3. Trình quản lý tệp Nemo (thay thế Dolphin):
  - Cài đặt:
      sudo pacman -S --needed --noconfirm nemo
  - Giao diện thân thiện, kéo thả mượt mà, hỗ trợ thùng rác, chuột phải đầy đủ tính năng.
  - Cấu hình mở mặc định dạng cửa sổ nổi (floating) 1100x700 ở giữa màn hình.
  - Từ khóa tìm kiếm nhanh: "f", "file", "nemo", "quan li tep".

2.4. Trình quản lý tác vụ Task Manager (Mission Center):
  - Cài đặt:
      sudo pacman -S --needed --noconfirm mission-center
  - Tên lệnh thực thi: missioncenter (đã tạo symlink mission-center để tương thích).
  - Phím tắt mở nhanh: Ctrl + Shift + Escape (chuẩn Windows) hoặc click thẻ Performance.

2.5. Trình xem ảnh Loupe (thay thế qView):
  - Cài đặt:
      sudo pacman -S --needed --noconfirm loupe
  - Giao diện hiện đại, phóng to thu nhỏ mượt mà, hỗ trợ mở cửa sổ nổi floating.

2.6. Trình chụp và chỉnh sửa / chú thích ảnh Satty (satty):
  - Cài đặt:
      sudo pacman -S --needed --noconfirm satty slurp grim wl-clipboard
  - Tính năng: Chụp vùng màn hình tùy chọn, hỗ trợ vẽ mũi tên, tô màu, vẽ khung chữ nhật,
    viết chữ (text), che mờ (blur) thông tin nhạy cảm.
  - Tích hợp script ~/.local/bin/satty-shot.sh: Tự động sao chép ảnh vào clipboard ngay
    khi chụp xong và cho phép nhấn Enter để lưu lại.

2.7. Trình quay video màn hình Kooha (kooha):
  - Cài đặt:
      sudo pacman -S --needed --noconfirm kooha
  - Tính năng: Quay video màn hình chất lượng cao trên Wayland, hỗ trợ định dạng MP4, GIF, WebM.
  - Hỗ trợ quay toàn màn hình hoặc khoanh vùng khu vực cần quay, ghi kèm âm thanh mic/hệ thống.

2.8. Bộ công cụ văn phòng tương thích Microsoft Office - OnlyOffice (onlyoffice-bin):
  - Cài đặt:
      paru -S --needed --noconfirm onlyoffice-bin
  - Tính năng: Soạn thảo văn bản Word (.docx), bảng tính Excel (.xlsx), trình chiếu PowerPoint (.pptx)
    với độ tương thích định dạng cao và giữ nguyên định dạng phong cách Microsoft Office.

2.9. Trình phát hình nền động Video Anime 4K - Mpvpaper & MPV (mpvpaper, mpv):
  - Cài đặt:
      sudo pacman -S --needed --noconfirm mpvpaper mpv ffmpeg
  - Tính năng: Chạy mượt mà video chất lượng cao 4K làm hình nền động cho Hyprland
    với mức tiêu thụ phần cứng cực thấp nhờ phần cứng tăng tốc (hwdec=auto).
  - Tích hợp script ~/.local/bin/livewall-ctl để đổi video, đổi theme màu động theo video.

2.10. Quản lý mã nguồn Git & Công cụ dòng lệnh GitHub CLI (git, gh):
  - Cài đặt:
      sudo pacman -S --needed --noconfirm git wtype
  - Quản lý phiên bản mã nguồn, clone repository và mô phỏng phím bấm cho Wayland.

3. CẤU HÌNH TERMINAL KITTY TIỆN LỢI NHƯ WINDOWS (COPY / PASTE DỄ DÀNG)
================================================================================
Mặc định trên Linux Terminal, phím Ctrl + C dùng để ngắt lệnh (SIGINT) và không thể
dùng để Copy như trên Windows, gây khó khăn cho người dùng quen Windows.

Đã cấu hình lại file ~/.config/kitty/kitty.conf để hỗ trợ đầy đủ:
  - copy_on_select yes:
      Tự động Copy văn bản vào bộ nhớ đệm ngay khi dùng chuột kéo bôi đen chữ,
      không cần bấm bất kỳ phím nào!
  - map ctrl+c copy_or_interrupt:
      Phím Ctrl + C thông minh:
      + Nếu đang bôi đen chọn chữ -> Bấm Ctrl + C sẽ là COPY văn bản.
      + Nếu không bôi đen -> Bấm Ctrl + C sẽ là hủy/ngắt lệnh như bình thường.
  - map ctrl+v paste_from_clipboard:
      Bấm Ctrl + V để DÁN (PASTE) trực tiếp nội dung vào terminal giống hệt Windows.
  - map ctrl+shift+c copy_to_clipboard
  - map ctrl+shift+v paste_from_clipboard

4. CẤU HÌNH BỘ GÕ FCITX5 & TỰ ĐỘNG CHUYỂN EN KHI PHỤP MÀN HÌNH / KHÓA MÁY
================================================================================
4.1. Cài đặt bộ gõ tiếng Việt Fcitx5 Bamboo:
  sudo pacman -S --needed --noconfirm fcitx5 fcitx5-bamboo fcitx5-gtk fcitx5-qt fcitx5-configtool

4.2. Biến môi trường bộ gõ trong ~/.config/uwsm/env:
  export XMODIFIERS=@im=fcitx
  export QT_IM_MODULE=fcitx

4.3. Khởi động Fcitx5 cùng Hyprland trong ~/.config/hypr/config/autostart.lua:
  hl.exec_cmd("fcitx5 -d")

4.4. Tự động chuyển về bộ gõ EN (keyboard-us) khi PHỤP MÀN HÌNH / KHÓA MÁY:
  Vấn đề: Khi gập màn hình laptop hoặc khóa máy, nếu bộ gõ đang ở chế độ tiếng Việt (Telex)
  thì khi mở máy lên gõ mật khẩu sẽ bị sai mật khẩu do dính dấu.
  
  Giải pháp toàn diện đã triển khai:
  - Tạo script: ~/.local/bin/auto-en-daemon.py
    + Lắng nghe sự kiện UPower "LidIsClosed": Bất kể khi nào nắp laptop gập xuống hoặc mở lên,
      nó lập tức kích hoạt lệnh: fcitx5-remote -s keyboard-us
    + Lắng nghe tín hiệu D-Bus logind "PrepareForSleep": Khi máy tính chuẩn bị sleep / suspend
      hoặc thức dậy, tự động chuyển về EN.
    + Lắng nghe Hyprland socket2: Khi layer lockscreen xuất hiện hoặc màn hình tắt (DPMS 0),
      tự động chuyển về EN.
  - Đăng ký Systemd User Service: ~/.config/systemd/user/auto-en.service
    + Lệnh kích hoạt:
        systemctl --user daemon-reload
        systemctl --user enable --now auto-en.service
  - Phím tắt khóa màn hình (Super + L):
    Đã gộp lệnh: fcitx5-remote -s keyboard-us && noctalia msg session lock

5. CẤU HÌNH PHÍM TẮT HỆ THỐNG HYPRLAND & CAELESTIA SHELL
================================================================================
5.1. Danh sách phím tắt hệ thống đang hoạt động:

  - Alt + Space:
      Mở thanh tìm kiếm ứng dụng (Launcher). Tự động chuyển bộ gõ sang EN khi mở.
      Ưu tiên đề xuất:
        + Gõ 'f'      -> Mở Trình quản lý tệp (Nemo)
        + Gõ 'c'      -> Mở Cốc Cốc Browser
        + Gõ 'v'/'vs' -> Mở VS Code
        + Gõ 'a'      -> Mở Antigravity
  
  - Super + V (Win + V):
      Mở bảng lịch sử Clipboard thông minh (Clipse):
        + Hỗ trợ xem trước hình ảnh (IMAGE THUMBNAIL) trực quan thay vì chỉ hiện text thô.
        + Hỗ trợ lưu trữ cả văn bản lẫn hình ảnh.
        + Tìm kiếm nhanh, ghim mục yêu thích (phím P), xem toàn màn hình (phím Space).
        + Chọn mục và Enter để copy vào bộ nhớ tạm.
  
  - Win + Shift + S hoặc phím Print:
      Chụp màn hình và mở trình chỉnh sửa chú thích Satty (chuẩn Windows Snipping Tool):
      Khoanh vùng chọn -> Tự sao chép ảnh vào Clipboard + Mở cửa sổ Satty để vẽ/ghi chú.

  - Win + Alt + R hoặc Ctrl + Alt + R:
      Mở trình quay video màn hình Kooha.

  - Win + Alt + W:
      Chuyển nhanh sang video hình nền động 4K tiếp theo trong thư mục ~/Ảnh động/Wallpapers.

  - Win + Alt + C:
      Đổi nhanh phong cách bảng màu Material You (Dynamic, Catppuccin, Tokyo Night, Dracula, Nord,...).

  - Win + Alt + B:
      Bật / Tạm dừng phát video hình nền động (chuyển đổi linh hoạt giữa ảnh tĩnh và video).

  - Bấm và nhả phím Win (Super_L release):
      Bật / tắt hiển thị thanh taskbar dọc bên trái màn hình.

  - Alt + Shift:
      Bật / tắt kho cửa sổ phụ (Special Workspace / Scratchpad).
  
  - Win + Space (Super + Space):
      Chuyển đổi qua lại giữa bộ gõ Tiếng Việt (Bamboo) và Tiếng Anh (Fcitx5).
  
  - Super + L:
      Khóa màn hình và tự chuyển bộ gõ về EN.
  
  - Super + Q hoặc Alt + F4:
      Đóng cửa sổ đang chọn.
  
  - Super + F:
      Bật / tắt chế độ toàn màn hình (Fullscreen).
  
  - Super + Enter hoặc Super + T:
      Mở Terminal Kitty.

5.2. Tính năng tương tác trên thanh Performance (Caelestia Top Drawer):
  - Khi rê chuột lên cạnh trên màn hình để mở Dashboard / Performance:
  - Người dùng có thể nhấn chuột trực tiếp vào từng thẻ phần cứng:
      + Nhấn thẻ CPU     -> Mở Mission Center chuyển thẳng đến biểu đồ CPU
      + Nhấn thẻ GPU     -> Mở Mission Center chuyển thẳng đến biểu đồ GPU
      + Nhấn thẻ Memory  -> Mở Mission Center chuyển thẳng đến biểu đồ RAM
      + Nhấn thẻ Disk    -> Mở Mission Center chuyển thẳng đến biểu đồ Ổ cứng
      + Nhấn thẻ Network -> Mở Mission Center chuyển thẳng đến biểu đồ Mạng

6. CẤU HÌNH CỬA SỔ NỔI & TỐI ƯU WORKSPACE GAME TRONG HYPR-USER.LUA
================================================================================
6.1. Quy tắc cửa sổ nổi (Floating Windows):
Trong file ~/.config/hypr/config/windowrules.lua và ~/.config/caelestia/hypr-user.lua:
Các ứng dụng tiện ích được cấu hình để luôn mở dạng cửa sổ nổi ở giữa màn hình:
  hl.window_rule({
      match = { class = "^(nemo|Nemo|org.gnome.Loupe|io.missioncenter.MissionCenter)$" },
      float = true,
      size = { 1100, 700 },
      center = true,
  })

  hl.window_rule({
      match = { class = "com.cachyos.clipboardviewer" },
      float = true,
      size = "480 650",
      center = true,
  })

6.2. Tối ưu hóa điều hướng Game tự động sang Workspace 5 (Màn 144Hz):
Trong file ~/.config/caelestia/hypr-user.lua:
Tất cả các tựa game và trình giả lập được tự động ghim cố định sang Workspace 5 trên màn hình laptop 144Hz (eDP-2) để đạt tần số quét và FPS cao nhất:
  hl.workspace_rule({ workspace = "5", monitor = "eDP-2" })

  local gameClasses = "^(steam_app_.*|gamescope|[Mm]inecraft.*|net\\.minecraft\\.client.*|org\\.lwjgl.*|osu!|ryujinx|yuzu|rpcs3)$"

  hl.window_rule({
      match = { class = gameClasses },
      workspace = "5",
  })

  hl.window_rule({
      match = { title = "^([Mm]inecraft.*)$" },
      workspace = "5",
  })

7. CẤU HÌNH HÌNH NỀN ĐỘNG ANIME 4K & THEME ĐỘNG (LIVEWALL-CTL)
================================================================================
- Thư mục chứa video hình nền: ~/Ảnh động/Wallpapers
- Script điều khiển: ~/.local/bin/livewall-ctl
- Cơ chế:
  + Dùng mpvpaper phát video nền phần cứng (hardware accelerated).
  + Tự động trích xuất frame đại diện của video để làm bảng màu Dynamic cho Caelestia Shell.
  + Tự động khởi chạy livewall-ctl init khi vào Hyprland.

8. CẤU HÌNH MÀN HÌNH KÉP (DUAL MONITOR SCALE 1.0)
================================================================================
Trong file ~/.config/hypr/config/monitors.lua:
Đồng bộ tỉ lệ hiển thị sắc nét chuẩn 1080p, không bị mờ hay phóng đại:
  - Màn hình ngoài LG (HDMI-A-1): 1920x1080@60Hz, vị trí 0x0, scale 1.0.
  - Màn hình laptop (eDP-2): 1920x1080@144Hz, vị trí 1920x0, scale 1.0.
  - Cốc Cốc và thanh công cụ Noctalia / Caelestia hiển thị đúng tỷ lệ chuẩn, sắc nét.

9. CẤU HÌNH ỨNG DỤNG MẶC ĐỊNH (MIME ASSOCIATIONS)
================================================================================
Trong file ~/.config/mimeapps.list:
  - Mở file văn bản, mã nguồn (.txt, .py, .c, .js, .md, .json, .log,...): VS Code (code.desktop).
  - Mở tài liệu văn phòng (.docx, .xlsx, .pptx): OnlyOffice (onlyoffice-desktopeditors.desktop).
  - Mở hình ảnh (.png, .jpg, .jpeg, .webp, .bmp, .gif): Loupe (org.gnome.Loupe.desktop).
  - Mở thư mục: Nemo (nemo.desktop).
  - Mở liên kết web: Cốc Cốc (coccoc-browser-stable.desktop).

10. TÍNH NĂNG KHỞI ĐỘNG SANG WINDOWS 1-CLICK (BOOT-TO-WINDOWS)
================================================================================

11. HƯỚNG DẪN TỰ ĐỘNG THỰC THI CHO ANTIGRAVITY TRÊN MÁY MỚI
================================================================================
Khi bạn thiết lập trên máy mới, bạn chỉ cần mở Antigravity và nhắn:
  "Hãy đọc thư mục /home/nttdz/Dự án/SetupCachyOSCoban/Caidathethong và cài đặt hệ thống giống như tài liệu này."

Khi đó Antigravity sẽ:
  1. Chạy script: bash "/home/nttdz/Dự án/SetupCachyOSCoban/Caidathethong/install.sh"
  2. Cài đặt toàn bộ phần mềm từ Official Repo và AUR.
  3. Đồng bộ toàn bộ các file trong thư mục "configs/" vào ~/.config và ~/.local:
     - configs/kitty/*       -> ~/.config/kitty/
     - configs/caelestia/*    -> ~/.config/caelestia/
     - configs/quickshell/*   -> ~/.config/quickshell/
     - configs/hypr/*        -> ~/.config/hypr/
     - configs/bin/*         -> ~/.local/bin/ (cấp quyền chmod +x)
     - configs/systemd/*     -> ~/.config/systemd/user/
     - configs/desktop/*     -> ~/.local/share/applications/
     - configs/mimeapps.list -> ~/.config/mimeapps.list
  4. Kích hoạt dịch vụ:
     systemctl --user daemon-reload
     systemctl --user enable --now auto-en.service
     systemctl --user enable --now clipboard-daemon.service
  5. Khởi chạy hình nền động và nạp lại Hyprland:
     livewall-ctl init
     hyprctl reload
  Toàn bộ hệ thống mới sẽ hoạt động y hệt như thiết bị hiện tại chỉ trong vài phút!
