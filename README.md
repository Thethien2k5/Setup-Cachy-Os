# SetupCachyOsCoban

Bộ tài liệu cấu hình, kịch bản tự động hóa và các tệp tinh chỉnh hệ thống CachyOS (Hyprland WM).
Giúp triển khai và tái tạo nhanh môi trường làm việc trên thiết bị mới.

## Cấu trúc thư mục
- `Caidathethong/`
  - `Caidathethongcoban.txt`: Hướng dẫn chi tiết toàn bộ thiết lập hệ thống.
  - `install.sh`: Script cài đặt 1-chạm cho máy mới.
  - `configs/`: Bản sao lưu toàn bộ các tệp cấu hình thực tế (Hyprland, Scripts, Systemd service, Desktop entries).
